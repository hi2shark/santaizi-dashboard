# 计划任务与触发任务

进入 **任务** 页面（`/cron`）可以管理在服务器上执行的命令。

## 任务类型

| 类型 | 说明 |
|------|------|
| 计划任务 | 使用 cron 表达式定期执行 |
| 触发任务 | 由监控告警的“失败触发任务”/“恢复触发任务”调用 |

## 创建任务

1. 点击 **添加任务**。
2. 填写：
   - **名称**：任务名称
   - **类型**：`0`=计划任务，`1`=触发任务
   - **计划**：计划任务时填写 cron 表达式，如 `0 3 * * *`
   - **命令**：在服务器上执行的具体命令
   - **覆盖范围**：
     - 全部服务器（忽略特定）
     - 仅特定服务器
     - 仅忽略特定服务器
     - 由触发该任务的服务器执行（仅触发任务）
   - **推送通知**：执行成功时发送通知
   - **失败通知**：执行失败时发送通知
3. 保存后，计划任务会按 cron 表达式调度，触发任务等待被监控事件调用。

## Cron 表达式示例

| 表达式 | 含义 |
|--------|------|
| `0 3 * * *` | 每天凌晨 3 点 |
| `*/5 * * * *` | 每 5 分钟 |
| `0 0 * * 0` | 每周日 0 点 |

## 手动触发

在任务列表中点击 **手动触发** 可以立即执行一次该任务。

对应 API：

```http
GET /api/cron/:id/manual
```

## 与监控联动

在 **服务监控** 中配置：

- **失败触发任务**：监控异常时自动执行（如重启服务）
- **恢复触发任务**：监控恢复时自动执行（如发送恢复脚本）

触发任务默认由触发该事件的服务器执行。

## 查看执行结果

任务执行后，可以在任务列表中查看最近执行时间和结果状态。成功/失败通知会发送到对应的通知组。
