# 内网穿透（NAT）

NAT 功能可以将外部请求通过 Dashboard 代理到指定服务器的指定主机，适用于内网服务暴露。

## 进入方式

**内网穿透** 页面（`/nat`）。

## 创建 NAT 规则

1. 点击 **添加 NAT**。
2. 填写：
   - **名称**：规则名称
   - **服务器**：选择目标服务器
   - **主机**：目标服务器上的目标地址，如 `127.0.0.1:8080`
   - **域名**：绑定到该规则的域名
3. 保存。

## 使用方式

将域名的 DNS 解析指向 Dashboard 所在服务器。当请求到达 Dashboard 时，系统根据 `Host` 头匹配 NAT 规则，将流量转发到对应服务器的 `主机` 地址。

## 示例

| 字段 | 值 |
|------|-----|
| 名称 | 内网博客 |
| 服务器 | 家中 NAS |
| 主机 | `127.0.0.1:8080` |
| 域名 | `blog.example.com` |

将 `blog.example.com` 解析到 Dashboard 公网 IP，访问该域名即可转发到家中的 `127.0.0.1:8080`。

## 注意事项

1. 该功能会占用 Dashboard 的 HTTP 端口，建议配合反向代理使用。
2. 目标服务器需要在线且 Agent 正常运行。
3. 生产环境建议额外配置访问控制，避免未授权访问内网服务。
